Formação de Preço de Venda

Custo do produto + despesas percentuais sobre a venda + margem desejada. Parâmetros globais valem para todos os produtos que não tiverem parâmetros próprios.

Parâmetros globais de precificação

Na margem sobre o preço, o divisor é 1 − (impostos + comissão + despesas + inadimplência + margem)/100. Se a soma chegar a 100%, o preço é matematicamente impossível e o sistema avisa.

Configurações

Parâmetros de cálculo de custo, classificação de variação e limites de alerta.

Cada etapa vira uma coluna no quadro da linha de produção. Ordens em etapas removidas voltam para a primeira etapa.

Desligado, o sistema bloqueia a baixa quando o consumo real supera o saldo — evita custo de material distorcido.

Banco de dados na nuvem

Todos os cadastros, produções, movimentações e configurações ficam gravados no banco de dados Postgres da Vercel (Neon). Cada alteração é enviada na hora; os outros usuários recebem o aviso em tempo real e buscam só o que mudou. Enquanto não é confirmada pelo banco, a alteração fica guardada neste navegador — não é preciso salvar nem sincronizar manualmente.

Dados do Sistema

O backup em JSON é uma cópia de segurança completa. Restaurar um backup substitui os dados da nuvem para todos os usuários.
